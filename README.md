# Thực Hành Cài Đặt và Sử Dụng SASS CLI

## 1. Kiểm tra môi trường
- Kiểm tra Node.js: `node -v`
- Kiểm tra npm: `npm -v`
- Cài đặt SASS toàn cục: `npm install -g sass`
- Kiểm tra phiên bản SASS: `sass -v`

## 2. Các lệnh SASS CLI đã thực hành
- Biên dịch 1 file: `sass scss/styles.scss css/styles.css`
- Chế độ theo dõi tự động (--watch): `sass scss/styles.scss css/styles.css --watch`
- Biên dịch toàn bộ thư mục: `sass scss/:css/ --watch`
